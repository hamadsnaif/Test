# Bounce - الكرة الحمراء (المراحل 1 إلى 3)

إعادة بناء دقيقة للعبة Bounce الأصلية من نوكيا (Series 40، 2002)، المراحل الثلاث الأولى، بملف HTML واحد.

## ما الذي يطابق اللعبة الأصلية
- الرسومات مأخوذة من صفحة السبرايت الأصلية للعبة (`objects_nm.png`): الطوب، الكرة، الحلقات، الأشواك، البلورة، الباب، وأيقونات الشريط السفلي.
- خرائط المراحل 1 و2 و3 الأصلية كاملة، بحجم بلاطة 12 بكسل وشاشة 128×128 مع تمرير رأسي بالصفحات كما في الأصل.
- الكرة الكبيرة والمنافخ والمفرغات، الماء (الكرة الكبيرة تطفو والصغيرة تغرق)، المنحدرات، الطوب المطاطي، الأشواك المتحركة، ومعزّز السرعة.
- فيزياء الكرة من كود اللعبة الأصلي: الجاذبية، قوة القفز، الارتداد عند الهبوط، السرعة القصوى والاحتكاك، بمعدل 25 إطاراً في الثانية.
- قواعد التصادم الأصلية: المرور عبر الحلقات، حواف الحلقات، الأشواك، البلورة كنقطة إعادة ظهور، الكرة الزرقاء كحياة إضافية، والباب الذي يُفتح بعد جمع كل الحلقات.
- الأصوات الثلاثة الأصلية (الحلقة، الالتقاط، الانفجار) مفكوكة من ملفات النغمات الأصلية.
- النقاط: 500 للحلقة، 200 للبلورة، 1000 للحياة الإضافية، 5000 عند الخروج.

## التشغيل
افتح `index.html` في المتصفح، أو:

```
python3 -m http.server 8000
```

## التحكم
- ← → أو 4 / 6 للحركة، ↑ أو 2 أو المسافة للقفز
- على الجوال: أزرار اللمس أسفل الشاشة
