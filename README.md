# Bounce - الكرة الحمراء (المرحلة الأولى)

نسخة ويب من لعبة Bounce الشهيرة التي كانت على جوالات نوكيا ذات الشاشة الملونة، تحتوي على المرحلة الأولى فقط.

## التشغيل
افتح الملف `index.html` في أي متصفح حديث، أو شغّل خادماً محلياً:

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## التحكم
- الأسهم ← → أو A / D للحركة
- ↑ أو W أو المسافة للقفز
- على الجوال: أزرار اللمس أسفل الشاشة

## الهدف
اجمع كل الحلقات الزرقاء ثم ادخل باب الخروج. تجنب الأشواك، ولديك 3 كرات (أرواح).
