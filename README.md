# 🧱 تتريس — Nokia Tetris

نسخة ويب من لعبة **تتريس** الكلاسيكية بطابع هواتف نوكيا القديمة، مهيّأة للعب على **الآيفون**.
مبنية بـ HTML وCSS وJavaScript فقط، بدون أي مكتبات خارجية، وفي ملف واحد (`index.html`).

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

### على الآيفون (الطريقة المفضّلة)

1. افتح الرابط في Safari.
2. اضغط زر **المشاركة** ← **إضافة إلى الشاشة الرئيسية**.
3. شغّلها من الأيقونة لتعمل بملء الشاشة كأنها تطبيق، بدون شريط المتصفح.

## التحكم

| الإجراء | على الجوال | على الحاسب |
|---------|-------------|-------------|
| تحريك يمين/يسار | زرّا `←` و`→` أو السحب على الشاشة | الأسهم |
| تدوير | زر `تدوير` أو نقرة على الشاشة | السهم لأعلى أو `X` (و`Z` للعكس) |
| نزول سريع | زر `نزول` أو السحب للأسفل | السهم لأسفل |
| إسقاط فوري | زر `إسقاط سريع` أو مسحة سريعة للأسفل | `مسافة` |
| إيقاف / متابعة | زر `إيقاف` | `P` |
| بدء / إعادة | زر `إعادة` | `Enter` |

الضغط المستمر على أزرار الحركة يكرّرها تلقائياً كما في الألعاب الأصلية.

## المميزات

- قواعد تتريس المتعارف عليها: 7 قطع، ونظام الدوران المعياري (SRS) مع تصحيحات الجدار.
- توزيع «الحقيبة السباعية»: كل 7 قطع تظهر كلٌ منها مرة واحدة، فلا تطول فترة انتظار القطعة الطويلة.
- **ظل القطعة** يوضّح مكان هبوطها قبل الإسقاط — يجعل اللعبة أسهل فهماً وأمتع.
- مهلة تثبيت قصيرة بعد ملامسة الأرض تتيح تعديل الوضع في اللحظة الأخيرة (إحساس سلس).
- ألوان هادئة وواضحة لكل قطعة على خلفية داكنة مريحة للعين.
- النقاط: 100 / 300 / 500 / 800 لكل 1–4 صفوف مضروبة في المستوى، ونقاط إضافية للإنزال والإسقاط.
- المستوى يرتفع كل 10 صفوف وتزداد السرعة تدريجياً حتى المستوى 20.
- معاينة القطعة التالية، وعدّاد الصفوف والمستوى، وأفضل نتيجة محفوظة في المتصفح (`localStorage`).
- مؤثرات صوتية بطابع الهاتف القديم مولّدة عبر Web Audio (بدون ملفات صوت)، مع لحن اللعبة الشهير كخيار اختياري — ويمكن كتم أيٍّ منهما ويُحفظ الاختيار.
- تهيئة كاملة للآيفون: منع التكبير والسحب العرضي، مراعاة الحواف الآمنة (notch)، تخطيط مختلف للوضع الأفقي، وإيقاف تلقائي عند مغادرة التطبيق.
