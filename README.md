# 🐍 Nokia Snake II — لعبة الدودة

نسخة ويب من لعبة الدودة الأسطورية التي جاءت مع هواتف نوكيا (Snake II)، مبنية بـ HTML وCSS وJavaScript فقط بدون أي مكتبات خارجية.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## التحكم

| الإجراء | المفاتيح |
|---------|----------|
| الحركة | الأسهم، أو `W A S D`، أو `2 4 6 8` (مثل لوحة نوكيا) |
| إيقاف / متابعة | `مسافة` أو `P` |
| بدء / إعادة | `Enter` |
| القائمة | `Esc` |
| الجوال | السحب على الشاشة أو أزرار الاتجاهات على الهاتف |

## المميزات

- شاشة LCD خضراء بطابع نوكيا 3310 مع شبكة البكسل.
- 9 مستويات سرعة، والنقاط لكل طعام = رقم المستوى (كما في الأصل).
- «الحشرة» الإضافية تظهر كل 5 قطع طعام، ونقاطها تقلّ كلما تأخرت في التقاطها.
- أفضل نتيجة محفوظة في المتصفح (`localStorage`).
- إيقاف تلقائي عند مغادرة التبويب، ودعم كامل للمس.
